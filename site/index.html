How the product works

Walkthrough of recognition, translation, OBS, VR modules, style, and More.

Live — the control desk

Start and stop recognition, watch status chips on every tab, read the live transcript, and preview subtitle output before it hits OBS or VR.

  • Press Start — recognition uses your latest settings, even if you have not saved yet.
  • Choose Web Speech or Local ASR when the module is ready.
  • Status bar stays pinned on all tabs — full KPI on Live, compact strip elsewhere.
  • Compact layout fits a secondary monitor; optional compact Chrome worker from Live.

Web Speech — Chrome worker

Production mode browser_google runs Google Chrome Web Speech in a separate window — full UI with address bar by default, or optional compact --app= from the Live tab.

  • Microphone permission is granted inside Chrome (getUserMedia).
  • Isolated worker profile under user-data; anti-throttling flags on Windows.
  • Choose the spoken language and optional restart tuning in Settings.
  • Recognition runs in its own Chrome window — leave it open behind OBS or your game.

Local ASR — offline Parakeet

Optional module: offline Parakeet via ONNX Runtime (CPU or CUDA). No Chrome worker when Live mode is Local ASR.

  • Open Modules → Local ASR and finish setup until ready.
  • Lazy-download ORT, model weights, optional Silero VAD and CUDA redist.
  • Native mic capture (cpal) with WebRTC or Silero VAD.
  • Same subtitle / translation / overlay path as Web Speech after ingest.

Translation — up to four lines

Seventeen providers with queueing, cache, and stale-drop protection. ASR still works with translation turned off (source-only).

  • Up to four translation lines (source text is separate).
  • Keyless options: Google Web, Free Web Translate, Bing Translator.
  • Optional realtime translation — captions update while you speak, without waiting for the phrase to finish (off by default).
  • Memory/disk cache; late translations allowed; completed blocks stay until the next phrase finalizes.

Subtitles — overlay layout

Control which lines appear on the OBS overlay, their order, preset, scroll speed, and how long completed text remains visible.

  • Presets: single, dual-line, stacked + compact spacing (URL query overrides available).
  • Subtitle scrolling keeps captions full-size — long lines scroll vertically; speed is adjustable.
  • TTL / lifecycle settings keep completed text stable during the next partial.
  • Drag lines to choose which language appears on top in OBS.

OBS — Browser Source & CC

Primary output is a lightweight vanilla overlay page over WebSocket. Optional Closed Captions via OBS WebSocket are mainly for Twitch.

  • Add Browser Source → http://127.0.0.1:8765/overlay
  • Copy URL / open overlay helpers live on the OBS tab.
  • Closed Captions: meant for Twitch stream captions (other uses are uncommon).
  • After app updates, reload the Browser Source so scroll / style assets refresh.

Modules — sidecar windows

Compact cards open TTS, Twitch, Local ASR, VRChat, and SteamVR HUD. Enable each module, then close the window — output keeps running.

  • Square cards with status badges and a short help popup.
  • Theme presets hot-apply to every open module window and the Chrome worker.
  • Profiles and factory reset include all module configs together.
  • Official NVIDIA, VRChat, and SteamVR branding on the cards.

VRChat — Chatbox OSC

Social output: pipeline finals go to the VRChat Chatbox over OSC. Other players see the text — this is not a headset HUD.

  • Modules → VRChat → enable output → Start on Live → close the window.
  • OSC 127.0.0.1:9000 / 9001 · max 144 characters / 9 lines · no KAT.
  • What to send matches OBS CC modes, including {source} / {tr1}…{tr4} templates.
  • Optional pause on MuteSelf / AFK; Chatbox auto-clear (default 5 s).

SteamVR — wearer HUD

Wearer-only OpenVR overlay in PCVR. Stream viewers still use OBS; Quest standalone cannot show this HUD.

  • Start SteamVR from the module hero card, then Enable HUD + Live Start.
  • Attach to HMD, controller (wrist / palm / above), or world.
  • What to show: source plus enabled translation lines.
  • Manual SteamVR exit does not auto-relaunch — start again from the module.

TTS — subtitle speech

Optional module that speaks finalized subtitle lines. Requires Live Start while enabled; closing the window does not stop playback.

  • Open from Modules → TTS (separate window, /tts).
  • Speak translated or source lines as they finalize.
  • Google HTTP proxy or Python sidecar engine; Native or Sonic playback.
  • Output device and tempo are configured in the TTS module, not OBS.

Twitch — IRC, events, and TTS

Separate module for Twitch IRC (up to five channels), EventSub alerts (follow / sub / raid / cheer), and optional chat + event TTS independent of subtitle speech. Enable-without-window; OAuth redirect stays on /tts.

  • Open from Modules → Twitch (/twitch).
  • Connect with Twitch OAuth (re-authorize after EventSub); IRC and EventSub auto-connect when enabled.
  • Own TTS engine, playback sliders, per-event speak templates, filters, and output device.
  • Test phrase and clear queue without waiting for chat.

Style — look of the captions

Fonts, colors, outline, shadow, backgrounds, and animated entrance effects — shared by dashboard preview and OBS overlay.

  • Built-in and creative presets; Save after edits.
  • Per-slot overrides for source and each translation line.
  • Effects: fade, slide-up, zoom, blur-in, glow, and more.
  • UI Theme gallery with live hover preview — dashboard and modules, not the OBS overlay glyphs.

More — replace, profiles, tools

Word replace, profiles, diagnostics, theme, and factory defaults — everything that sits beside the live pipeline.

  • Word replace fixes ASR mistakes (and optional masking) before translation and outputs.
  • Profiles save dashboard + TTS + Twitch + Local ASR + VRChat + SteamVR together.
  • Factory reset restores the default profile and all module configs in one step.
  • UI Theme, Tools & Data, and Help live under More.

Quick start

Five steps from installer to live captions.

  1. Install

    Run the Windows x64 setup from the latest GitHub Release (v0.7.0+).

  2. Launch

    Open Kagevi Subtitles — the dashboard opens on Live.

  3. Add OBS source

    Browser Source → http://127.0.0.1:8765/overlay

  4. Start recognition

    Web Speech (leave the Chrome window open) or Local ASR when ready — then press Start.

  5. Optional VR

    Modules → VRChat or SteamVR HUD → enable → keep Live running. PCVR only for the HUD.
